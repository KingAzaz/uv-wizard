# MIT open-source core, paid Pro add-on after v1

UV Wizard's core is MIT-licensed, developed in public, and gives away the whole one-button Quest result for free. Money comes from a separate paid Pro package, sold on BOOTH and/or Jinxxy after v1, holding power features: alpha handling (a second material, or removing hidden layers), PC atlasing, priority painting and batch processing. The core has to beat free TexTransTool and AAO to win users. Research found that donations alone earn little at solo scale, and that a free MIT core plus a paid package (Light Limit Changer v2, Poiyomi Pro) is the model that sustains VRChat tools.

## Considered Options

- **Closed source**: protects revenue, but goes against ecosystem norms and the existing public repo.
- **Free plus a supporter variant only**: the most goodwill, but too little money to sustain the work.
- **Source-available licence**: not open source by OSI's definition, and it puts off contributors.

## Consequences

- MIT can't be taken back for code already released. Anything moved into Pro later must be new work, not a relicence of core code.
- Pro must never gate the core's headline result. Move a core feature into Pro and you break the promise.
